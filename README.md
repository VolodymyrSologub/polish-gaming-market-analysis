# 📊 Polish Gaming Market Analysis (Steam Data)

### 📌 Project Overview
This project provides a comprehensive data-driven analysis of the Polish game development industry on Steam. Using a dataset of **85,000+ games**, I extracted and processed data for **97+ Polish studios** to understand market leaders, revenue distribution, and pricing strategies.

### 🛠️ Key Methodology
* **Revenue Estimation:** Applied the **Boxleiter Method** (Estimated Sales = Total Reviews * 30) to calculate gross revenue.
* **Market Share Analysis:** Identified that the top 2 studios (CD Projekt RED & Techland) control approximately **80% of the total estimated revenue** in the Polish segment.
* **Pricing Correlation:** Analyzed how price points affect user reception using logarithmic scaling to handle high-performing outliers.

### 💻 Technical Stack
* **Python** (Pandas for data wrangling, Matplotlib for advanced visualization).
* **Google Colab** (Development environment).
* **Market Intelligence** (Business metrics and revenue forecasting).
